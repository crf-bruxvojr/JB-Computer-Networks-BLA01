This is the BLA for Network foundations. This project required me to research a variety of topics around the fundamentals of networks, including The Internet and Network Fundamentals, Network Edge and Network Core, Communication and Network Protocols, Understanding Network Performance, and Network Security. This was an interesting project, as it forced me to read up more on a variety of networking protocols and what not through the assigned textbook, as the lectures did not cover everything that was needed to be discussed within the project. It was rather interesting seeing how it all worked together, like Routers, Switches, and Links all worked together in order to send various packets of data wherever they needed to go. Another example of protocols all working together is HTTP, TCP, IP, and DNS functioning in tandem in order to send users to whatever destination they want without us having to memorize IP addresses. Lastly, packets in general were quite interesting, and how much of the internet revolves around them, and various actions involving them.
The Internet and Network Fundamentals - what a computer network is, and some common terms and usage
Network Edge and Network Core - the ingredients of and differences between the network edge and core
Communication and Network Protocols - A variety of protocols that work together to send people to places
Understanding Network Performance - various causes and symptoms of network delay
Network Security - Methods of security and attacks
